# NutriSan

Equilibrio · Salud · Bienestar

App web de NutriSan (Lic. Agustina Ayelén Sandoval): consultorio y portal del paciente, instalable en el celular.

- Consultorio: https://nutrisan-agustinasandoval.github.io/nutrisan/
- Los datos de los pacientes no se guardan acá: quedan en el dispositivo del consultorio y en el link personal que recibe cada paciente.
